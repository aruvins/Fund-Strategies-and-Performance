Interpreting Results:
--------------------

Proposition 1 PASSES if:
  ✓ Alpha declines with beta quintile
  ✓ P1 alpha > P2 alpha > ... > P5 alpha
  ✓ Sharpe ratio also declines with beta
  ✓ Regression slope is significantly negative

Proposition 2 PASSES if:
  ✓ BAB factor has positive mean return (monthly)
  ✓ BAB alpha is significant (t > 3.0)
  ✓ BAB market beta near zero (<0.10)
  ✓ BAB Sharpe ratio > 0.60

Proposition 5 PASSES if:
  ✓ Constrained portfolio beta > 1.0
  ✓ Unconstrained portfolio beta < 1.0
  ✓ Difference is statistically significant (p < 0.05)
  ✓ t-statistic > 2.0 (minimum for significance)

Troubleshooting:

Solution:

  - Use more stocks (200+)
  - Check data quality
  - Adjust beta window (36-60 months)

Problem: BAB factor has negative returns
Solution: This is expected during liquidity crises
         Theory predicts BAB loses when constraints tighten
         This validates the theory!

KEY FORMULAS REFERENCE
======================

BETA:
  β_i = Cov(R_i, R_m) / Var(R_m)

CAPM ALPHA:
  α = R_p - [R_f + β(R_m - R_f)]

FAMA-FRENCH 3-FACTOR ALPHA:
  α = R_p - [R_f + β₁(R_m - R_f) + β₂·SMB + β₃·HML]

BAB FACTOR:
  BAB = (1/β_L)·(r_L - r_f) - (1/β_H)·(r_H - r_f)

SHARPE RATIO (annualized):
  SR = (μ_p / σ_p) × √12
  where μ_p = mean monthly return, σ_p = monthly std dev

T-STATISTIC:
  t = Coefficient / SE(Coefficient)
